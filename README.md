# amirator — personal site

Single static page. No build step.

## Deploy (pick one)
- **Netlify Drop:** drag this folder onto https://app.netlify.com/drop
- **GitHub Pages:** push `index.html` + `og-image.png` to a repo named `amirator.github.io`, then Settings → Pages → Deploy from branch `main`.
- **Vercel / Cloudflare Pages:** import the folder as a static site, no framework, output dir `/`.

For link previews, change `og:image` in `index.html` to the full URL once the site is live (e.g. `https://amirator.github.io/og-image.png`).
